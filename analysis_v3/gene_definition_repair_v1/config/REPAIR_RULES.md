# Canonical definition correction v1

Authorized after known v2 and Batches01–04 results. This is retrospective error correction and impact analysis, not preregistration or independent validation. No original file is replaced. No publication authorized.

## Source-only rules, before corrected disease association

Reopen all five original transcript sheets, retaining Excel row, original cell text, source comparison and every duplicate. Use the archived human NCBI GeneInfo snapshot to isolate a mapping-policy correction from a database-version update. Unique exact official symbol takes priority, then unique case-folded official symbol, then unique synonym; ambiguous and unmapped records are not guessed. Explicit historical Excel date conversion is logged. No source or target P-value breaks a mapping tie.

Within each source comparison and GeneID, collapse identical rows without increasing evidence. All deposited rows for that GeneID must have finite, nonzero and concordant effect signs; otherwise retain the GeneID as a within-source direction conflict, without assigning a signed program membership. A gene must meet the unchanged source thresholds (adjusted P < 0.05 and absolute log2FC > 0.585) in every mapped deposited row to enter the repaired signed parent. Threshold disagreement is a separate excluded category. This conservative all-record rule does not select the smallest P or most extreme effect. Median source effect is annotation only, not a new test or tie breaker. The supplied sheets are incomplete differential-expression lists, not a full tested transcriptome; absence means not present in the deposited list.

Reconstruct intersections AFTER canonicalization. Same-direction eligible shared genes form core. Parent genes absent from the other source's deposited mapped list form residual. Shared opposite-direction genes form cross-source conflict/excluded, retaining both source directions. Parent genes whose partner is ambiguous, discordant or not threshold-eligible form partner-unresolved/excluded, not residual. Parent = core + residual + explicit excluded, all disjoint, and every bin retains the parent's signed direction. Within-source conflicts do not enter the signed parent. Late all-cell and late-neuron use each other as partners; severity uses late-neuron. Early and Xenium are repaired signed parents without an invented decomposition.

No changing thresholds, direction or membership after target associations. Frozen repaired members and source audit must be hashed before disease analysis. Analyses whose inputs do not depend on these programs are not rerun. Original score-policy variants are retained as historical comparators, never silently harmonized.

## Background correction

Primary impact attribution first changes membership on inherited backgrounds. A separate outcome-statistic-free sensitivity uses all mapped, finite expression rows in the actual deposited expression sheet, median per GeneID per sample, with no target DE statistic, target P, adjusted P or outcome label in gene selection or duplicate aggregation. For nonnegative normalized abundance, remove all-zero genes; for rlog retain all finite genes, do not interpret negative values as unexpressed and never convert to counts. Target aliases use the same canonical resolver. hDRG/JCI historical DE-statistic eligibility and target-P duplicate priorities are recorded explicitly. No claim that a deposited selected expression sheet is a complete transcriptome.

Ten repaired programs, five existing Batch04 endpoints, every positive and negative retained. Signed within-sample average percentile rank(up) minus rank(down), common whole-background ranks, at least 10 measured members in EACH arm. Comparison outputs retain old cached values and clearly distinguish recalculated common-method P/q from historical published P/q. Two-sided donor-level tests; hDRG labels permute within verified sex strata; other binary endpoints fix group sizes; GSE148059 uses all 77 with 28 Intermediate fixed and an OLS Degenerator–Regenerator contrast. Reuse Batch04 exact <=100000 allocations, otherwise 9999 permutations with plus-one; bootstrap 2000 within groups/verified strata, percentile 95% intervals. BH over ten programs per endpoint/version for descriptive association impact. No pooling the ALC products.

After canonical and measured-bin identity checks only, inherit Batch04 full/restricted/joint maxT/core-minus-residual real benchmark, Holm over all eligible family-endpoint tests separately per background. The joint maxT corrects component selection. Matched random partition reference uses 999 label-blind mean-quintile/MAD-tertile/source-direction matched splits, fixed excluded bin, same measured union; report conditional percentile and duplicate split count, not external-validation P. No selection of best split. Master seed 20260910 with SHA256-derived independent endpoint/task streams. No new simulations, networks, pathway/TF screens or guessed patient joins.

Dependent original cross-tissue/protein/reference/proxy outputs require a separate dependency inventory and like-for-like adapters under this same frozen membership, not automatic relabeling as unaffected. They remain pending until actually rerun or a justified unavailable status is documented.
