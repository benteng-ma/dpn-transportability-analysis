DPN corrected manuscript: reviewer-facing code and numerical archive

Scope
-----
This archive accompanies the Scientific Reports submission. It contains the scripts, analysis-family registers,
environment records, compact machine-readable results and reader tables needed to inspect the corrected and
extended analyses reported in the manuscript. Source datasets are not redistributed; they remain available from
the public repositories cited in the manuscript.

Important provenance boundary
-----------------------------
The historical GitHub/Zenodo release predates the canonical-definition correction and should not be used as the
numerical reference for the submitted manuscript. This archive does not claim to be a clean-environment rerun of
every historical raw workflow. It preserves the correction and public clinical extension code, key outputs, and
status/independence records used for manuscript integration.

Large genome-wide EWAS and RRBS result tables are omitted from this lightweight submission archive because the
underlying public source data are cited and the manuscript/Supplementary Information report the declared families
and compact results. The full local review bundle is retained by the authors.
