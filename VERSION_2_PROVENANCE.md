# Version 2 provenance and interpretation boundary

Version 2.0.0 was assembled after the v1.0.0 public release and after the original results were known. It includes a standard-GeneID correction, strict-background impact analysis, bounded method audits and public-data extensions. These activities are not represented as prospective registration.

The immutable v1.0.0 release remains available for historical comparison. For v2, a file under `analysis_v3/gene_definition_repair_v1/strict_background_addendum/consolidated_results/` takes precedence over a same-purpose earlier record. Other results retain the source named in the final evidence and claim registers.

The portable public copy changes only path declarations and recorded local path strings. It does not change program membership, direction, coverage rules, numerical results, model families, P values or q values. Original large public inputs remain referenced rather than redistributed.

The repository does not claim that every historical raw workflow can be executed end-to-end without obtaining the cited public source files. Frozen outputs, checksums, source registers and semantic tests support audit of the reported analyses. A passing software or hash check is not scientific validation.
